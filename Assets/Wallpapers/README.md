# Wallpaper assets

The wallpaper catalogue is maintained in `Systems/wallpapers.js`. Keep the existing image assets here when applying the 1.1 upgrade. The catalogue expects these filenames:

- `aurora-drift.jpg`
- `ocean-glass.jpg`
- `rose-horizon.jpg`
- `forest-mist.jpg`
- `lavender-cloud.jpg`

These source images were not part of the files uploaded for this upgrade, so they are intentionally not replaced with guessed or placeholder artwork.
